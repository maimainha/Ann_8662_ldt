# Ann_8662_ldt
Dự án thiết kế, tổng hợp và mô phỏng mạng Nơ-ron nhân tạo (Artificial Neural Network - ANN) với cấu trúc (8-6-6-2) hoàn toàn bằng ngôn ngữ mô tả phần cứng (Verilog ). Mục tiêu của dự án là triển khai thành công AI Core lên dòng chip FPGA Cyclone IV E để xử lý dữ liệu với độ trễ cực thấp.
